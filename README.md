# DataSet
# Student AI, Social Media & Health Data Analysis

## Overview
This project explores relationships between technology usage, lifestyle habits, and health metrics among students.
Using Python, I analyzed a dataset containing approximately 16,000 student records and created visualizations to investigate how factors such as social media usage, AI tool usage, sleep, and physical activity relate to mental and physical health scores.
The goal of this project was to practice data analysis, visualization, and interpretation using Python while identifying meaningful patterns within a large dataset.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Datascience
- Jupyter Notebook
- Visual Studio Code

## Dataset
The dataset contains student demographic, technology usage, lifestyle, and health information.
Variables analyzed include:
- Age
- Gender
- Education Level
- Daily Social Media Hours
- Daily AI Tool Usage Hours
- Sleep Hours
- Physical Activity Hours
- Mental Health Score
- Physical Health Score

## Questions Explored
This analysis focuses on several questions:

1. Is social media usage associated with mental health scores?
2. Is AI tool usage associated with mental health scores?
3. Is sleep duration associated with mental health scores?
4. Is physical activity associated with physical health scores?
5. Does average AI tool usage differ between education levels?

## Visualizations
### Social Media Usage vs Mental Health

A scatter plot and linear trend line were used to examine the relationship between daily social media usage and mental health scores.
The visualization shows a downward overall trend, suggesting that higher social media usage is associated with lower mental health scores within this dataset.

### AI Tool Usage vs Mental Health

AI tool usage was compared with mental health scores to determine whether increased AI usage was associated with differences in reported mental health scores.
A scatter plot and trend line were used to visualize the overall relationship.

### Sleep vs Mental Health

Sleep duration was compared with mental health scores to explore whether students who sleep more tend to have different mental health scores.

### Physical Activity vs Physical Health

Physical activity hours were compared with physical health scores.
The visualization was used to examine the relationship between increased physical activity and reported physical health.

### AI Tool Usage by Education Level

Average daily AI tool usage was calculated for each education level.

| Education Level | Average Daily AI Usage |
|---|---:|
| High School | 2.57 hours |
| College | 2.59 hours |
| University | 2.62 hours |

AI tool usage was very similar across the three education groups in this dataset.

## Data Visualization Techniques

Because the dataset contains thousands of observations, scatter plots were created using smaller, transparent data points to reduce visual overlap.
Linear trend lines were added to make the overall direction of relationships easier to identify.
Bar charts were used when comparing categorical groups such as education level.

## Key Takeaways

This project demonstrates:

- Importing and exploring a large dataset
- Selecting relevant variables for analysis
- Working with numerical and categorical data
- Grouping data and calculating averages
- Creating scatter plots and bar charts
- Using linear trend lines to visualize relationships
- Improving visualization readability for large datasets
- Interpreting patterns without assuming correlation implies causation
